# Plan: Risk Areas — Intent Extension

> Status: DRAFT
> Created: 2026-06-25

## Problem

The Intent card shows `intent`, `in_scope[]`, `out_of_scope[]`. The design spec
includes a **RISK AREAS** row — lightweight semantic signals (e.g. "Auth surface
touched", "New dependency: ioredis") derived from the same cheap LLM call that
already runs `deriveIntent()`. No extra model call; no extra cost.

This plan also resolves two existing blockers in client shared contracts that
prevent `cd client && pnpm typecheck` from passing:
1. `client/src/vendor/shared/contracts/trace.ts` — `PromptAssembly` missing
   `intent: z.string().nullish()` (present in server copy since Intent Layer impl)
2. `client/src/vendor/shared/contracts/platform.ts` — `review_intent` default
   still `openai/gpt-4.1` (server already updated to `openrouter/deepseek/deepseek-v4-flash`)

```typescript
// ---- Risk Areas ----
export const RiskAreaKind = z.enum([
  'security',
  'dependency',
  'performance',
  'data',
  'api_change',
  'other',
]);
export type RiskAreaKind = z.infer<typeof RiskAreaKind>;

export const RiskArea = z.object({
  title: z.string(),   // e.g. "Auth surface touched", "New dependency: ioredis"
  kind: RiskAreaKind,
});
export type RiskArea = z.infer<typeof RiskArea>;

// ---- Intent ----
export const Intent = z.object({
  intent: z.string(),
  in_scope: z.array(z.string()),
  out_of_scope: z.array(z.string()),
  // nullish + transform guards against model returning null instead of []
  risk_areas: z.array(RiskArea).nullish().transform(v => v ?? []),
});
export type Intent = z.infer<typeof Intent>;
```

Apply identical change to **both** copies.

### TASK-003: DB schema + migration

**Scope:** backend / database

**Owned Paths:**
- `server/src/db/schema/reviews.ts`
- `server/src/db/migrations/` (generated)

**Change:** add `riskAreas` column to `prIntent` table.

Before (`reviews.ts` lines 48–55):
```typescript
export const prIntent = pgTable('pr_intent', {
  prId: uuid('pr_id')
    .primaryKey()
    .references(() => pullRequests.id, { onDelete: 'cascade' }),
  intent: text('intent').notNull(),
  inScope: jsonb('in_scope').$type<string[]>().notNull().default(sql`'[]'::jsonb`),
  outOfScope: jsonb('out_of_scope').$type<string[]>().notNull().default(sql`'[]'::jsonb`),
});
```

After:
```typescript
export const prIntent = pgTable('pr_intent', {
  prId: uuid('pr_id')
    .primaryKey()
    .references(() => pullRequests.id, { onDelete: 'cascade' }),
  intent: text('intent').notNull(),
  inScope: jsonb('in_scope').$type<string[]>().notNull().default(sql`'[]'::jsonb`),
  outOfScope: jsonb('out_of_scope').$type<string[]>().notNull().default(sql`'[]'::jsonb`),
  riskAreas: jsonb('risk_areas')
    .$type<Array<{ title: string; kind: string }>>()
    .notNull()
    .default(sql`'[]'::jsonb`),
});
```

Then run:

### TASK-004: Repository — update `upsertIntent` + `getIntent`

**Scope:** backend

**Owned Path:** `server/src/modules/reviews/repository/pull.repo.ts`

**Change:** include `riskAreas` in writes and reads.

`upsertIntent` (lines 49–62) — add to values and set:
```typescript
export async function upsertIntent(db: Db, prId: string, intent: Intent): Promise<void> {
  await db
    .insert(t.prIntent)
    .values({
      prId,
      intent: intent.intent,
      inScope: intent.in_scope,
      outOfScope: intent.out_of_scope,
      riskAreas: intent.risk_areas,          // ← new
    })
    .onConflictDoUpdate({
      target: t.prIntent.prId,
      set: {
        intent: intent.intent,
        inScope: intent.in_scope,
        outOfScope: intent.out_of_scope,
        riskAreas: intent.risk_areas,        // ← new
      },
    });
}
```

`getIntent` (lines 64–68) — include in return:
```typescript
export async function getIntent(db: Db, prId: string): Promise<Intent | undefined> {
  const [row] = await db.select().from(t.prIntent).where(eq(t.prIntent.prId, prId));
  if (!row) return undefined;
  return {
    intent: row.intent,
    in_scope: row.inScope,
    out_of_scope: row.outOfScope,
    risk_areas: row.riskAreas ?? [],         // ← new
  };
}
```


3. **`formatIntent`** — append risk areas to the prompt string fed to review agents:

```typescript
function formatIntent(data: Intent): string {
  const risks = data.risk_areas.length > 0
    ? `\nRisk areas: ${data.risk_areas.map(r => `${r.title} (${r.kind})`).join('; ')}`
    : '';
  return (
    `Summary: ${data.intent}\n` +
    `In scope: ${data.in_scope.join('; ')}\n` +
    `Out of scope: ${data.out_of_scope.join('; ')}` +
    risks
  );
}
```
